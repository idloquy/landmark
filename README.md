# Landmark

Landmark is an Android app for marking locations built with Kotlin and Jetpack Compose.

## Features

- Display the current coordinates
- Mark the current coordinates with arbitrary descriptions
- Browse and manage the list of saved coordinates
- Copy saved coordinates to the clipboard
